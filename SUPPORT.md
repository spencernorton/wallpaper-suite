# Support

- **Something is broken** — [open a bug report](https://github.com/spencernorton/wallpaper-suite/issues/new/choose).
- **A question, or an idea** — [Discussions](https://github.com/spencernorton/wallpaper-suite/discussions).
- **A security problem** — [private vulnerability reporting](https://github.com/spencernorton/wallpaper-suite/security/advisories/new), never a public issue. See [SECURITY.md](SECURITY.md).
- **Documentation** — the README in this repository.

This is one developer's project, maintained in the open; there is no
support contract and no e-mail address. Issues are answered as time allows,
and the newest tagged release is the only one that gets fixes.

If this saves you time, you can [support its development](https://buy.stripe.com/8x26oH2U44f65TRe574wM04).

Wallpaper Suite is part of [NorviOS](https://github.com/spencernorton/norvi-os).
